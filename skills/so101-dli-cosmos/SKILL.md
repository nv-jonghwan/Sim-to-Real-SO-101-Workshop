# Work through Cosmos augmentation

Read [the Cosmos lesson](../../docs/14-strategy3-cosmos.md), its Korean catalog
and referenced interactive video comparison before answering. Distinguish the
instructor demonstration from a student-requested experiment; use the lesson's
prepared media and models for the ordinary comparison.

Explain why visual diversity can help transfer, then compare corresponding
source/augmented frames: vial/rack geometry, gripper visibility, motion timing,
contact, object identity and temporal consistency. Preserve action/state labels,
episode boundaries and wrist/external camera correspondence. An attractive
video alone does not establish a useful training example or a better policy.

For an explicit generation request, inspect the course's actual example,
required model/tool, input format and available resources. Do not invent CLI
flags, use unrelated Cosmos3 defaults, or start a remote service from a theory
question. Keep originals, generated outputs and prompts identifiable; inspect
the complete output before preparing any augmented dataset.

For claims about policy improvement, route to the course evaluation workflow
with fixed tasks, starting conditions and trial counts. Explain limitations and
failure cases from the comparison; retain the source lesson link in the answer.
