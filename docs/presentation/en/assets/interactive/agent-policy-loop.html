1. Pause and observe

At each decision the simulation stops and the harness reads the current scene: the external and wrist camera images and the six joint values (five arm angles plus the gripper). These are the same inputs a recorded SO-101 episode contains.

The agent works from camera images and joints alone. The evaluator's success or timeout result is never one of its inputs.

2. Build the prompt

The harness packs three things next to the current observation. The first is the task text, "Pick up the vial and place it in the rack". The second is a recorded demonstration with its camera frames, joints, and example action targets. The third is the previous decision: the observation the agent saw last time, the actions or waypoints it chose, and a short plan note.

The demonstration is how we hand the agent an example of the motion we want. It arrives in the prompt rather than through training.

3. Ask the agent

The prompt goes to a remote model service as a single request. The simulator stays paused until the answer comes back, so slow inference never turns into extra motion in the scene. Only the model runs remotely. The simulator, the harness, and the evaluator stay on the local machine.

The agent replies with absolute joint targets, either as a dense list or as waypoints.

4. Check and adapt

Before anything moves, the local runtime parses the reply and validates it. The action adapter then interpolates the targets and converts them into simulator units.

The result is one joint target for each control step of the simulation.

5. Execute, then repeat

The robot follows up to H of those targets before the harness observes again. The chunk length is a setting you choose. Wall-clock time per decision is set by inference, which can take several seconds, and the simulation waits for it. A shorter chunk corrects course more often but pays for more inference. A longer chunk spends more of each wait on motion.

A native evaluator checks for success or timeout and records the outcome to the logs. Its result is never shown to the policy.
