System 1: generate a chunk of actions

GR00T 1.7 · Flow-matching action head

The action head uses vision-language features and robot state to generate a sequence of joint commands. The saved processors convert the model representation into commands compatible with the robot.

Example

Act, then observe the result

Inference · Fixed weights, changing observations

The rollout controller applies returned actions and obtains fresh observations for later predictions. Feedback changes the model’s inputs; ordinary inference does not update its weights.

Example

At the nominal 30 Hz rate, 16 actions span about 0.53 seconds of command time, excluding inference and network delay. Verify that the achieved starting pose matches the actual training data before comparing policies.

Robot state: where the arm is now

Input · Current joint positions

Robot state conditions the action head together with the visual-language features. Joint order, units, calibration, and processor settings must agree between data collection and rollout.

Example

A relative arm target is interpreted from the observed pose. Relative actions do not make an unseen starting pose equivalent to one covered by the training data.
