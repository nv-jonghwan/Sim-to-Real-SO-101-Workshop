AI Days Seoul 2026 · DLI HTML Presentation (English)

Open index.html in Chrome or Edge after extracting the entire archive.
Keep index.html, assets/, and guide/ together. No server or installation is required.
Press P for the presenter window, F for fullscreen, and G for contents.
Presenter: use Left/Right to run previous/next cues; in-script buttons control slides,
media, diagrams, popups, and scrolling. Open both windows in the same browser.
The guide and bundled media work locally. External sites and embedded online services
such as YouTube, GitHub, and Hugging Face require internet access.
