Articulation / robot

Joints, actuators, physical properties.

Assets

Static and dynamic objects, lights and materials.

Sensors

Cameras, contact sensors, etc..

Actions

Action terms map controller outputs into commands for the simulated robot.

Scene

Asset placement and parallel environments.

Simulation settings

With physics_dt = 1/60 and decimation = 2, each control step advances two physics steps: a 30 Hz control rate.

Events

Startup terms prepare the scene; reset terms vary a new episode; periodic terms run at configured intervals.

Observations

Build inputs from state and sensor data.

Terminations

Success, failure, and time limits determine when an episode ends. An ending alone is not evidence of success.

Rewards

Reward terms produce task signals. Recording demonstrations does not update a policy from these rewards.

Environment

Coordinates scene, managers, stepping, and episode resets.

Policy

During evaluation the policy predicts actions from observations. During collection a teleoperator or scripted controller can supply actions instead.
