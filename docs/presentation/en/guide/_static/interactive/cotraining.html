1. Review both sources

Simulation makes repeated collection and controlled variation easier. Real demonstrations show the cameras and robot response at a deployment station. Check the task instruction, episode starts, purposeful motion, and successful outcomes in both collections. Each source has limits; neither guarantees coverage of every future condition.

Compare the two data sources

2. Check exposure

Training samples individual frames or short windows, not whole episodes, so each data source’s share depends on how many frames it contributes. Longer episodes contribute more samples. Setting an exact ratio between sources requires a sampler that supports source weights, and repeating real samples doesn’t add new real-world variety.

Understand source sampling

3. Train one policy

One GR00T 1.7 policy learns from both sources. Match joint order, units, action convention, gripper calibration, camera geometry and names, frame rate, and instruction. Keep the original datasets and their revisions traceable. The workshop provides a prepared co-trained checkpoint; the optional training workflow is a separate activity.

Review dataset compatibility

4. Evaluate separately

Compare the co-trained checkpoint with the simulation-only baseline under matched evaluation conditions. Record simulation outcomes separately from autonomous physical trials. Match the actual training-data starting distribution, including any continuation data, and verify the achieved pose under supervision. Improvement from co-training is something to measure.
