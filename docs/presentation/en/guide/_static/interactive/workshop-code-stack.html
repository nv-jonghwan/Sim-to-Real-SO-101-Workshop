Workshop code

Combines the task configuration, controller, recording, and evaluation. The bridge converts LeRobot commands into simulation joint commands and converts observations back for recording or inference.

LeRobot

Provides teleoperator and robot interfaces, the dataset format, and policy tools. During collection the leader supplies actions; during evaluation a policy supplies them. The workshop recorder saves images, joint state, and actions.

Isaac Lab

Organizes assets, observations, action terms, resets, and success checks. Its environment step connects the selected physics and rendering backends to the vial-to-rack task.

USD assets

Describe the workstation geometry, materials, camera properties, and physical properties. Isaac Lab loads these assets for simulation, and the Omniverse libraries manage their rendered scene.

Newton

Advances robot and object dynamics using the configured MJWarp solver and collision pipeline. Updated poses drive the simulated scene and become joint observations.

Omniverse libraries

ovstage manages the USD scene used for rendering. ovrtx renders wrist and external RGB images from the updated scene. ovstream takes GPU renders and stream them to the browser. Isaac Lab exposes those camera results as observations.
