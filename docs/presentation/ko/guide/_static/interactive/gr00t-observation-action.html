Vision: observe the task

입력 · Wrist 및 external RGB 이미지

두 view는 vial, rack, gripper에 대해 상호 보완적인 정보를 제공합니다. Wrist view는 arm과 함께 변하므로, 시작 pose가 달라지면 policy가 보는 장면도 달라집니다.

예시

External 이미지에서 보이는 vial이 wrist 이미지에서는 gripper에 일부 가려질 수 있습니다. Camera key와 preprocessing을 checkpoint와 호환되게 유지합니다.

Language: specify the task

입력 · Instruction 문구

Task instruction은 이미지, state와 함께 학습된 동작의 조건이 됩니다. Language-conditioned model도 요청된 로봇 동작을 충분히 다루는 training data가 필요합니다.

예시

“Pick up the vial and place it in the rack”은 목표를 설명하며, 사람이 작성한 joint angle sequence를 제공하는 것은 아닙니다.

System 2: interpret images and language

GR00T 1.7 · Vision-language backbone

Cosmos-Reason2-2B는 action head가 사용하는 vision-language feature를 제공합니다. “System 2”는 이 perception과 reasoning 역할을 나타내는 개념적 명칭입니다. 이 workshop에서 별도로 프로그래밍하는 planner를 뜻하지 않습니다.

예시

Vial과 rack을 나타내는 visual feature는 action 생성 전에 placement instruction의 영향을 받습니다. 이 diagram은 사람이 읽을 수 있는 계획이 반환된다는 뜻이 아닙니다.

System 1: generate a chunk of actions

GR00T 1.7 · Flow-matching action head

Action head는 vision-language feature와 robot state를 사용하여 joint command sequence를 생성합니다. 저장된 processor가 model 표현을 로봇과 호환되는 command로 변환합니다.

예시

이 workshop에서는 arm에 relative target, gripper에 absolute target을 사용합니다. 문서에 지정된 16-action rollout 설정과 checkpoint에 맞는 processor를 사용하세요.

Act, then observe the result

Inference · Weight는 고정하고 observation은 갱신

Rollout controller는 반환된 action을 적용하고 다음 예측을 위한 새 observation을 얻습니다. Feedback은 model의 입력을 바꾸며, 일반적인 inference에서는 weight를 갱신하지 않습니다.

예시

명목상 30 Hz에서 16개 action의 command 실행 시간은 약 0.53초이며, inference와 network 지연은 제외한 값입니다. Policy를 비교하기 전에 실제 도달한 시작 pose가 training data와 맞는지 확인합니다.

Robot state: where the arm is now

입력 · 현재 joint position

Robot state는 vision-language feature와 함께 action head의 조건이 됩니다. Data 수집과 rollout에서 joint 순서, 단위, calibration, processor 설정이 일치해야 합니다.

예시

Relative arm target은 관찰된 pose를 기준으로 해석됩니다. Relative action을 사용한다고 해서 학습에서 보지 못한 시작 pose가 training data에 포함된 pose와 동등해지는 것은 아닙니다.
