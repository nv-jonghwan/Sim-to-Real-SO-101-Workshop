Dataset과 Model#

현재 workflow는 LeRobot으로 GR00T 1.7을 학습하고 Isaac Lab 3.0, Newton physics, ovrtx로 data를 기록합니다.

현재 Model 선택#

Base model은 nvidia/GR00T-N1.7-3B입니다. GR00T Post-Training으로 SO-101 task에 맞추세요. Base weight만으로는 task policy가 되지 않습니다.

아래 세 policy는 실습의 출발점입니다. 모두 GR00T 1.7이지만 training data와 camera 이름이 다릅니다. 세 checkpoint는 공개되어 있으며 원문에서 접근을 확인한 날짜는 2026년 10월 8일입니다.

Icon은 post-training에 사용한 data를 나타냅니다. 초록은 사용, 회색은 미사용입니다.

Sim-only policy는 action horizon 16, 30 Hz, simulated time limit 30초, scene seed 76000–76099, source f892b1a08c088e55156a389b3f1e42ab5eaa1049에서 simulation 100회 중 94회 성공을 기록했습니다. 이후 revision의 10-episode 실습 예상 점수나 실제 성공률·안정적인 복귀/재시작 성능을 뜻하지 않습니다. 선택된 Co-Trained checkpoint에는 공개 성공률이 없으므로 본인 station에서 비교하세요.

Johnny42: Real-to-Real Reference#

실제 demonstration 50개로 학습했으며 camera key는 wrist, front입니다. Action chunk와 execution horizon은 모두 16입니다. Training instruction Pick up the vials and put them in the yellow rack을 사용하세요. 고정된 configuration과 model card를 확인하세요.

Vision-Trainable 20k: Sim-Only Reference#

GR00T base에서 scripted Newton demonstration 500개로 20,000 update를 학습합니다. wrist, external을 사용하고 32-action-step supervision을 적용하며, 보고된 평가는 prediction당 16개 action을 실행합니다. Model card는 94/100 성공(Wilson 95% 구간 87.5–97.2%)을 보고합니다. 실제 예비 관찰에서는 가능성을 보였지만 gripper hesitation과 시작점 미복귀가 있었으며 집계된 실제 성공률은 없습니다.

Sim75 + Real10: Co-Trained Reference#

Simulation teleoperation episode 75개와 실제 demonstration 10개를 결합하고 학습 내내 총 85개를 함께 사용합니다. Simulation data는 Perception-DR environment이며 두 source 모두 wrist, external camera를 사용합니다.

Vision trainable, language frozen, effective batch 64(microbatch 16을 4 step 누적)로 20,000 update를 학습합니다. 16-action window와 relative arm action을 사용합니다. 공개 training recipe를 확인하세요.

조건을 맞춘 simulation 평가는 아직 남아 있으며 예비 실제 trial은 benchmark가 아닙니다. 같은 rollout 설정으로 simulation과 실제 동작을 비교하세요.

Workshop Container용 Model Download#

행사 station 준비에는 Workshop Preparation Reference에 따라 실습 model을 cache하세요.

hf CLI가 설치된 host의 cloned repository directory에서 실행합니다. Container 시작 전에 outputs/, datasets/, models/를 만드세요. Download는 자동 mount되는 models/에 저장합니다.

cd ~/Sim-to-Real-SO-101-Workshop
mkdir -p outputs datasets models
hf download sreetz-nv/so101-clean-up-vials-into-rack-50-groot-n17-relact-bs64-20k-20260628_johnny_42 --revision 981f41e4f5b4dda47c6583de502dcac258bf5312 --local-dir ./models/johnny42
hf download sreetz-nv/so101_newton_dr500_vision_h32_b32_20k_20260929 --revision bbfef9eaecc7a7654f42aaa4ceb95245bb140a53 --local-dir ./models/sim-vision-20k
hf download sreetz-nv/so101_real10_sim75_vision_h16_b64_20k_20261011 --revision c7e8049753be5629e73eda69b57a358146bbeb5d --local-dir ./models/sim75-real10

hf가 container에만 있다면 내부 /workspace/Sim-to-Real-SO-101-Workshop에서 세 hf download 명령을 실행합니다. 같은 host-mounted folder에 저장됩니다.

Container 실행 명령은 ./models를 /workspace/Sim-to-Real-SO-101-Workshop/models에 mount합니다. Image rebuild는 필요하지 않습니다. 평가 전에 container에서 model 하나를 선택합니다.

직접 Dataset과 Policy 만들기#

  1. Leader-arm demonstration을 <user>/so101_teleop_vials_newton에 수집하거나 Automated Data Collection으로 <user>/so101_auto_vials_newton을 기록합니다.

  2. 같은 repo ID와 --root ./datasets/<repo_id>로 lerobot-dataset-viz에서 episode를 검토하고 완성 dataset을 해당 Hub repo에 upload합니다.

  3. GR00T Post-Training으로 학습합니다. DATASET_NAME을 수집한 dataset으로 지정하세요. 예시 model 이름은 <user>/<dataset_name>_GR00T17, local checkpoint 위치는 outputs/train/ 아래입니다.

  4. 같은 policy를 simulation에서 먼저, 실제 robot에서 다음으로 평가합니다.

README의 mount 구성은 container 종료 후에도 dataset, download model, training output을 host에 보존합니다.

Checkpoint 호환성#

Weight, configuration, processor artifact를 포함한 LeRobot policy repo 또는 checkpoint의 pretrained_model directory를 사용하세요.

확인 사항:

  • GR00T 1.7 base model과 호환되는 LeRobot configuration

  • Checkpoint와 같은 image feature: 선택된 sim-only/Co-Trained policy는 observation.images.wrist, observation.images.external; Johnny42는 observation.images.wrist, observation.images.front

  • Joint 순서: shoulder pan, shoulder lift, elbow flex, wrist flex, wrist roll, gripper

  • 일치하는 joint normalization, camera calibration, task geometry, 30 Hz data

  • Gripper exclusion을 포함한 저장된 relative-action preprocessing/postprocessing

  • Checkpoint chunk size 이하의 evaluation action horizon

Camera rename map은 feature 이름만 바꿉니다. Camera geometry, joint 규약, raw Isaac-GR00T checkpoint format 차이를 해결하지는 못합니다.

호환되는 Policy Download#

  1. Container에서 인증하고 학습한 policy의 model ID를 설정한 뒤 download합니다.

hf auth login
export MODEL_ID=your_hf_username/so101_teleop_vials_newton_GR00T17
hf download "$MODEL_ID" --local-dir "./models/$MODEL_ID"

models/ mount가 download를 host에 보존합니다.

  1. Nested checkpoint가 있다면 평가용 pretrained_model directory를 선택합니다.

Repo root에 policy configuration, weight, processor가 있다면 같은 container shell에서 local 경로를 설정합니다.

export MODEL_ID="/workspace/Sim-to-Real-SO-101-Workshop/models/$MODEL_ID"

그렇지 않으면 MODEL_ID를 nested pretrained_model directory로 설정하세요. Simulation은 --pretrained_name_or_path "$MODEL_ID", 실제 rollout은 --policy.path="$MODEL_ID"로 전달합니다. Hub에서 직접 로드하려면 repository ID를 유지하고 local 경로 설정을 생략하세요.

System Identification 참고 자료#

System Identification은 측정 검토에 Anchor-Lab SO-101 telemetry를, actuator profile과 학습 기록에는 AnchorBench paired bundle을 사용합니다. Paired demonstration은 해당 비교의 policy-training data입니다.

Anchor-Lab은 signal-level telemetry, paired demonstration은 policy-training episode를 제공합니다. 비교 checkpoint는 GR00T N1.6 artifact이며 현재 과정의 GR00T 1.7 rollout을 대체하도록 검증되지 않았습니다.

이전 과정 Artifact#

이전 실습의 data와 policy 링크입니다. 전략 연구용 참고이며 현재 Newton/GR00T 1.7 artifact의 검증된 대체물이 아닙니다. Data 재사용 전에 camera schema와 calibration을 확인하세요. grootn16 repo의 이름을 바꿔 1.7 weight가 있는 것처럼 표현하지 마세요.
