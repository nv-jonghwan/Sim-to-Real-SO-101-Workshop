SO-101 Robot#

SO-101은 manipulation 연구와 교육을 위해 설계된 6-DOF (degrees of freedom) robot arm입니다. 아래 animation을 재생해 각 motion axis를 확인하세요.

SO-101 kit는 두 arm으로 구성됩니다.

  • Leader / Teleop arm: 손으로 움직여 실제 또는 simulation의 follower를 제어하고 demonstration을 기록합니다.

  • Follower / Robot arm: task를 수행하는 arm입니다. Teleoperation 중에는 leader를, 평가 중에는 policy를 따릅니다.

LeRobot 명령에서 --teleop는 leader, --robot은 follower를 지정합니다.

SO-101을 사용하는 이유#

SO-101은 다음 이유로 이 과정에 적합합니다.

  • Accessible: 교육과 연구에 적합한 가격

  • Well-documented: 충실한 문서와 community 지원

  • LeRobot integration: LeRobot ecosystem의 기본 지원

정밀한 task를 어렵게 만드는 요인:

  • Joint의 큰 Backlash

  • Joints loosen over time: Fastener를 조이면 3D-printed plastic이 압축되므로, link와 motor flange 사이의 체결력이 점차 약해집니다.

LeRobot Project#

LeRobot은 Hugging Face의 open-source library로, data 수집, 학습, robot 제어, policy 평가 도구를 제공합니다.

Community Datasets#

LeRobot은 Hugging Face Hub에서 LeRobot Dataset Format을 사용하는 community dataset을 제공합니다.

  • 수천 개의 robot demonstration

  • 다양한 robot platform

  • 여러 manipulation task

  • 상호 운용을 위한 표준 format

수집·학습·평가 workflow 미리 보기

Hugging Face Hub를 통한 Data Flow

Workshop은 하나의 so101-workshop container에서 LeRobot 도구를 사용합니다. Simulation recording 결과는 datasets/<repo_id>에 저장됩니다. Upload할 때도 같은 namespace를 사용하세요.

먼저 HF_USER를 본인의 Hugging Face username으로 설정하고 hf auth login으로 인증하세요.

중요

Dataset 수집과 검수를 완료한 뒤에만 아래 upload workflow를 실행하세요. DATASET_ID를 설정해도 데이터가 수집되거나 로컬 dataset이 생성되지는 않습니다. 빈 폴더나 내려받은 참고 표본은 수집이 완료된 dataset이 아닙니다. 수집 전에 workflow를 배우는 단계라면 아래 upload 명령은 지금 실행하지 마세요.

export DATASET_ID="${HF_USER:?Set HF_USER to your Hugging Face username first}/so101_teleop_vials_newton"
if [ -f "./datasets/$DATASET_ID/meta/info.json" ]; then
    hf upload "$DATASET_ID" "./datasets/$DATASET_ID" . --repo-type dataset &&
    hf repos tag create "$DATASET_ID" v3.0 --repo-type dataset --revision main &&
    hf download "$DATASET_ID" --repo-type dataset --revision v3.0 --local-dir "./datasets/$DATASET_ID"
else
    echo "Collect and inspect a completed dataset before uploading."
fi

같은 dataset에 나중에 다시 upload할 때는 tag를 갱신하세요.

참고: hf CLI 설치하기

hf CLI 설치하기

hf CLI는 huggingface_hub Python package에 포함되어 있습니다. Host 터미널에서 아래 명령을 실행해 사용자 전용 환경에 설치합니다.

hf 명령을 이미 사용할 수 있다면 설치를 건너뛰고 계정을 확인하세요. 이 Host 설치는 workshop Container 안의 설치와 별개입니다.

  1. 전용 Python 환경을 만듭니다.

    python3 -m venv ~/.local/share/hf-cli

  2. CLI가 포함된 package를 설치합니다.

    ~/.local/share/hf-cli/bin/python -m pip install "huggingface_hub==2.4.0"

  3. 사용자 bin 폴더에 명령을 연결합니다. 링크가 이미 있으면 ln 명령은 건너뜁니다.

    mkdir -p ~/.local/bin
ln -s ~/.local/share/hf-cli/bin/hf ~/.local/bin/hf

  4. 현재 터미널 세션의 PATH에 해당 폴더를 추가합니다.

    export PATH="$HOME/.local/bin:$PATH"
hash -r

    새 Bash 세션에서도 사용하려면 해당 폴더가 PATH에 없는 경우 export 줄을 ~/.bashrc에 추가합니다.

  5. CLI가 실행되는지 확인합니다.

    hf version
hf --help

  6. 필요하면 로그인한 뒤 Hub 작업에 사용할 실제 계정을 확인합니다.

    hf auth login
hf auth whoami

    HF_USER는 repository ID를 구성하는 별도의 shell 변수이며, 설정해도 로그인되지는 않습니다. 인증 정보는 로그인 입력창에서만 입력하세요.

Hugging Face CLI 공식 문서

Post-Training Pipeline

lerobot_agent와 leader arm으로 demonstration을 수집하거나, vials_state_machine으로 automated simulation collection을 수행합니다. 두 workflow 모두 datasets/<repo_id> 아래에 LeRobot dataset을 생성합니다. Upload와 학습 전에 lerobot-dataset-viz로 episode를 확인하세요.

lerobot-train에 --policy.type=groot와 --policy.base_model_path=nvidia/GR00T-N1.7-3B를 지정합니다. 전체 설정은 GR00T Post-Training에 있습니다.

Simulation Evaluation

같은 container terminal에서 python -m lerobot.async_inference.policy_server를 background로 시작한 뒤, prompt에서 lerobot_eval을 실행합니다. Client가 checkpoint를 선택하고 Isaac Lab에서 policy를 실행합니다. 전체 명령과 camera 요구사항은 Sim Evaluation을 확인하세요.

Real Robot Evaluation

학습한 LeRobot policy와 calibration된 follower의 robot 및 camera 설정으로 lerobot-rollout을 사용합니다. 명령은 Real Evaluation을 따르세요.

공통 workshop 환경에서 수집 → 검토 → 학습 → 평가 → 반복의 workflow를 진행합니다.

Hugging Face Hub Integration#

LeRobot은 다음 용도로 Hugging Face Hub를 사용합니다.

이 과정의 Hugging Face 활용 방법 자세히 보기

이 과정에서 Hugging Face를 활용한 방법

1. Demonstration 수집용 Dataset Format

모든 teleoperation 및 state machine 기반 procedural data에 LeRobot dataset format을 사용했습니다. Episode는 observation(예: camera image), robot state, action을 일관된 schema로 저장합니다. Simulation recording은 lerobot_agent --repo_id를 사용하며 local 경로는 datasets/<repo_id>로 정해집니다. Real recording은 lerobot-record에 --dataset.repo_id와 명시적인 --dataset.root를 지정합니다.

2. Dataset 공유

학습 재사용, 공유, version 관리를 위해 dataset을 Hugging Face Hub에 push했습니다. Recording 시 --dataset.repo_id=${HF_USER}/dataset_name과 --dataset.push_to_hub=true를 사용하거나, 기존 local dataset에는 hf upload를 사용했습니다. 학습 전에 Hub의 LeRobot Dataset Visualizer로 episode와 품질을 확인했습니다.

3. Co-Training용 Dataset Merge(sim + real, sim + Cosmos)

Co-training을 위해 여러 data source를 하나의 training dataset으로 합치거나 여러 차례 학습을 진행했습니다.

4. 평가 결과 공유

평가 결과와 policy checkpoint를 Hub로 공유했습니다. GR00T checkpoint 또는 LeRobot policy repo 등의 형태로 model을 upload해 다른 사람도 평가를 재현하거나 simulation과 실제 robot에서 같은 policy를 실행할 수 있도록 했습니다. 이 과정의 dataset과 model repo 링크는 모두가 같은 baseline과 co-trained model을 사용하도록 연결합니다.
