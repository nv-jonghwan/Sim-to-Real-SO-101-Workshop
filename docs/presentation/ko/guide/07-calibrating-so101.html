SO-101 Calibration#

Hands-on
이 Module에 필요한 준비물

실습입니다. SO-101 leader와 follower arm, USB cable, Using the Workspace에서 조립한 workspace가 필요합니다.

두 arm의 전원을 켜고 calibration한 뒤 joint range를 확인합니다. leader / teleop arm은 손으로 움직이는 arm이고, follower / robot arm은 task를 수행합니다.

팁

Hardware 문제가 발생하면 Troubleshooting Guide에서 흔한 문제의 해결 방법을 확인하세요.

학습 목표#

이 session을 마치면 다음을 수행할 수 있습니다.

  • 두 arm의 전원을 안전하게 켜기

  • 정확한 positioning을 위한 leader와 follower calibration

안전 지침#

Robot 전원을 켜기 전에 Safety 절차를 확인하세요.

Robot 전원 켜기#

실물 점검#

전원을 켜기 전에:

  1. Robot에 눈에 보이는 손상이 없는지 점검합니다.

경고

Leader는 5V, follower는 12V를 사용합니다. 전원 공급 장치를 바꿔 연결하지 마세요.

  1. 전원과 USB cable을 연결합니다.

  2. Robot 뒤쪽 control board의 power LED가 켜지는지 확인합니다.

  3. 두 arm을 USB cable로 computer에 연결합니다.

과정용 Docker Container 실행#

Arm을 다시 연결하면 USB port 할당이 바뀔 수 있습니다. 하나만 다시 연결하면 보통 바뀌지 않습니다. LeRobot port finder로 각 port를 확인하고 이후 명령에 사용할 값을 저장하세요.

  1. Host에서 terminal을 열고 home directory의 workshop folder로 이동합니다.

cd ~/Sim-to-Real-SO-101-Workshop

  1. 아직 시작하지 않았다면 이 folder에서 container를 시작합니다.

xhost +
docker run --name so101-workshop -it --rm --privileged --runtime=nvidia --network=host -e DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix -v ~/.Xauthority:/root/.Xauthority -v /dev:/dev -v /run/udev:/run/udev:ro -v ~/.cache/huggingface:/root/.cache/huggingface -v ~/.cache/ovrtx:/root/.cache/ovrtx -v ~/.cache/warp:/root/.cache/warp -v ./docker/env:/root/env -v ./source:/workspace/Sim-to-Real-SO-101-Workshop/source -v ./outputs:/workspace/Sim-to-Real-SO-101-Workshop/outputs -v ./datasets:/workspace/Sim-to-Real-SO-101-Workshop/datasets -v ./models:/workspace/Sim-to-Real-SO-101-Workshop/models so101-workshop:latest
이미 실행 중인 Container에 연결

Container가 이미 실행 중이고 추가 terminal이 필요하면 host에서 실행하세요. 이미 container prompt에 있다면 건너뜁니다.

docker exec -it so101-workshop bash

Workshop Python environment와 저장된 설정이 자동으로 로드됩니다.

Leader Arm Port 확인#

  1. 다음 명령을 실행해 port를 확인합니다.

lerobot-find-port

  1. 안내가 나오면 leader의 USB cable을 분리합니다.

Finding all available ports for the MotorBus.
['/dev/ttyACM0', '/dev/ttyACM1']
Remove the usb cable from your MotorsBus and press Enter when done.

  1. Cable을 분리한 뒤 Enter를 누릅니다.

The port of this MotorsBus is '/dev/ttyACM2'
Reconnect the USB cable.

이 예시에서 host가 할당한 port는 /dev/ttyACM2입니다. 연결 전후 device 목록의 차이로 찾습니다.

  1. Leader를 다시 연결하고 port를 저장합니다. /dev/ttyACM2를 도구가 찾은 port로 바꾸세요.

setenv TELEOP_PORT=/dev/ttyACM2 # replace with the detected leader port
setenv TELEOP_ID=orange_teleop # use this line as-is

참고

setenv는 repository의 docker/env에 설정을 저장하므로 다음 container session에서도 자동으로 로드됩니다.

Follower Arm Port 확인#

  1. Follower에서도 같은 절차를 반복하며, 안내에 따라 USB cable을 분리하고 다시 연결합니다.

lerobot-find-port

  1. /dev/ttyACM0를 도구가 찾은 port로 바꿔 follower port를 저장합니다.

setenv ROBOT_PORT=/dev/ttyACM0 # replace with the detected follower port
setenv ROBOT_ID=orange_robot # use this as-is

참고

ID는 arm의 calibration filename을 결정합니다. 같은 arm에는 모든 session에서 같은 ID를 사용하세요.

  1. 저장한 port와 ID를 확인합니다.

echo "Teleop port is ${TELEOP_PORT} with id ${TELEOP_ID}"
echo "Robot port is ${ROBOT_PORT} with id ${ROBOT_ID}"

  1. 이 terminal에서 calibration을 계속합니다.

중요

USB를 다시 연결한 뒤 할당이 바뀌었다면 port finder를 다시 실행하세요. 명령은 Quick Reference에도 있습니다.

Calibration 절차#

Calibration은 encoder reading과 각 link의 실제 위치를 맞춥니다. Policy는 joint position에 의존하므로, calibration이 잘못되면 의도하지 않은 움직임, task 실패, 충돌이 발생할 수 있습니다.

두 arm 모두 calibration 후 검증하는 같은 절차를 따릅니다.

Leader Arm Calibration#

  1. 저장한 port와 ID로 leader calibration 명령을 실행합니다.

lerobot-calibrate --teleop.type=so101_leader --teleop.port=$TELEOP_PORT --teleop.id=$TELEOP_ID

  1. 안내가 나오면 각 joint를 가동 범위의 중간에 놓습니다. 아래 pose와 같아지므로 사진에 맞추면 됩니다.

  1. Pose를 맞춘 뒤 Enter를 누릅니다.

  2. Wrist roll을 제외한 각 joint를 하나씩 전체 가동 범위로 움직입니다.

팁

  • 필요하면 같은 joint를 여러 번 움직여도 됩니다. Script가 최솟값과 최댓값을 기록합니다. 빠뜨린 joint가 있다면 calibration을 다시 실행하세요.

  • Mechanical end stop까지 움직이세요. Cable이나 장애물이 먼저 joint를 막아 잘못된 calibration이 기록되지 않도록 치웁니다.

  • 이 LeRobot 버전에서는 두 arm 모두 wrist roll range sweep이 필요 없습니다. Range는 자동으로 할당되지만, 아래의 초기 calibration pose에는 정확히 맞춰야 합니다. 움직이더라도 문제는 없습니다.

  1. 완료하면 Enter를 누릅니다.

  1. Follower로 넘어가기 전에 leader calibration을 확인합니다. Checker는 저장된 TELEOP_ID와 TELEOP_PORT를 사용합니다.

python docker/scripts/so101_check_calibration.py --arm teleop

  1. Report에 Arm: teleop와 본인의 calibration file이 표시되는지 확인합니다. WARN 또는 live OUT OF RANGE가 있으면 arm ID와 joint travel을 점검하세요. 문제를 수정하고 recalibration한 뒤 다시 검사합니다.

선택 사항: Calibration 검사 원리

Reference data는 이 workshop의 현장 운영을 위해 calibration한 WowRobo robot에서 얻었습니다. Checker는 arm별 reference dataset(teleop 10개 또는 follower 10개)과 비교하며, 평균 ±2 population standard deviation을 벗어나는 motion range를 표시합니다. 모든 reference range가 같다면 다른 값은 warning으로 표시됩니다. 이는 통계적 비교이며 calibration의 정오를 증명하지 않습니다. Reference sample도 ±2σ를 벗어날 수 있습니다.

선택한 arm이 연결되면 checker는 live encoder position도 읽습니다. “Live Encoder Positions”에서 OUT OF RANGE 결과를 확인하세요. Hardware 연결 없이 저장 파일만 검사하려면 --static-only를 추가합니다. 파일 검사만 PASS했다고 live position까지 검증된 것은 아닙니다.

특정 파일을 검사하려면 어느 arm 명령이든 --calibration /path/to/arm.json을 추가합니다. STATS_JSON environment variable로 선택한 arm의 reference 통계를 바꿀 수 있습니다.

Follower Arm Calibration#

  1. Follower calibration 명령을 실행합니다.

lerobot-calibrate --robot.type=so101_follower --robot.port=$ROBOT_PORT --robot.id=$ROBOT_ID

  1. Follower의 각 joint를 가동 범위 중간에 두어 calibration pose로 맞춥니다.

Calibration Pose 예시

Reading이 wrap around되지 않도록 wrist-roll 위치를 정확히 맞추세요.

  1. Enter를 눌러 calibration을 시작합니다.

  2. Wrist roll을 제외한 각 joint를 하나씩 전체 가동 범위로 움직입니다.

  1. 완료하면 Enter를 누릅니다.

  1. Teleoperation 전에 follower calibration을 확인합니다. Checker는 저장한 ROBOT_ID와 ROBOT_PORT를 사용합니다.

python docker/scripts/so101_check_calibration.py

  1. Report에 Arm: follower와 본인의 calibration file이 표시되는지 확인합니다. Teleoperation 전에 WARN이나 live OUT OF RANGE를 점검하고, 문제를 수정한 뒤 recalibration과 검사를 반복하세요.

LeRobot은 arm type과 ID별로 ~/.cache/huggingface/lerobot/calibration 아래에 calibration을 저장합니다.

External Camera 기울기를 Simulation에 맞추기#

Station마다 camera mount가 다릅니다. 제공된 policy의 학습 view와 같도록 실제 camera를 조정하세요.

Simulation camera는 수평에서 아래로 약 54°를 봅니다. 휴대전화 수평계 app으로 비슷한 기울기를 맞추세요.

  1. 휴대전화의 긴 모서리를 테이블 위에 대고 약 0°인지 확인합니다.

  2. 그 모서리를 camera 전면에 대고, lens 옆에서 위아래 방향으로 맞춥니다.

  3. 몇 도 이내의 오차로 아래쪽 약 54°가 되도록 mount를 조절합니다.

  4. 다음 실습에서 live view를 simulation과 비교하세요. Robot, rack, vial의 구도가 비슷해야 하며, camera 위치와 field of view도 중요합니다.

핵심 내용#

  • Arm별 port, ID, calibration file을 함께 관리하세요.

  • Calibration 시 wrist roll을 중앙에 맞추되 range sweep은 생략합니다.

  • Data 수집이나 policy 실행 전에 두 arm의 calibration과 camera view를 확인하세요.
