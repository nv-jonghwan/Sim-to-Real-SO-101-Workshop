Code와 Model 준비#

Hands-on
이 Module에 필요한 준비물

실습입니다. Ubuntu Linux, Git LFS가 포함된 Git, Docker, CUDA Toolkit, NVIDIA Container Toolkit, NVIDIA RTX GPU가 필요합니다.

Robot asset과 과정 media를 올바르게 내려받을 수 있도록, clone 전에 host에 Git LFS를 설치하고 초기화하세요.

git lfs install

Simulation, calibration, teleoperation, recording, GR00T 학습과 평가에 사용할 하나의 workshop image를 build합니다.

Ubuntu Linux 22.04보다 최신 버전에서 NVIDIA RTX 6000 Pro (Blackwell), RTX 5090 (Blackwell), RTX 6000 (Ada) GPU로 검증했습니다. Image를 build하기 전에 host software를 설치하세요.

Workshop Software#

구성 요소

Workshop 구성

Isaac Lab

3.0 development stack. docker/Dockerfile의 ISAACLAB_REF로 고정됩니다.

Physics

Newton with the MJWarp solver

Camera rendering

ovrtx. Isaac Lab에서 호환되는 ovrtx와 OVStage 버전을 제공합니다.

LeRobot

0.6.0. 학습, GR00T, async inference, visualization 지원 포함

Policy

GR00T 1.7. Post-training에 nvidia/GR00T-N1.7-3B 사용

Container

CUDA 13, Ubuntu 24.04, Python 3.12

이 workshop은 Isaac Sim 또는 Kit application 없이 실행됩니다. 별도 Isaac Sim 설치로 대체하지 말고 고정된 stack을 build하세요.

Repository Clone#

  1. Host에서 terminal을 열고, home directory에 repository를 clone한 뒤 해당 directory로 이동합니다.

cd ~
git clone --branch aidayseoul2026 --single-branch https://github.com/nv-jonghwan/Sim-to-Real-SO-101-Workshop.git
cd Sim-to-Real-SO-101-Workshop
git lfs pull

Workshop Container Build#

  1. Host의 repository root에서 image를 build하고 영구 output directory를 생성합니다.

docker build -t so101-workshop -f docker/Dockerfile .
mkdir -p outputs datasets models

같은 image로 simulation과 실제 robot 실습을 모두 진행합니다.

Workshop Container 시작#

  1. Host의 repository root에서 container를 시작합니다.

cd ~/Sim-to-Real-SO-101-Workshop

위 cd 명령에는 실제 저장소 경로를 사용하세요. ~/Sim-to-Real-SO-101-Workshop는 예시입니다. 같은 터미널에서 현재 폴더에 docker/Dockerfile과 source/가 있는지 확인한 뒤 다음 명령 블록을 실행하세요.

xhost +
docker run --name so101-workshop -it --rm --privileged --runtime=nvidia --network=host -e DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix -v ~/.Xauthority:/root/.Xauthority -v /dev:/dev -v /run/udev:/run/udev:ro -v ~/.cache/huggingface:/root/.cache/huggingface -v ~/.cache/ovrtx:/root/.cache/ovrtx -v ~/.cache/warp:/root/.cache/warp -v ./docker/env:/root/env -v ./source:/workspace/Sim-to-Real-SO-101-Workshop/source -v ./outputs:/workspace/Sim-to-Real-SO-101-Workshop/outputs -v ./datasets:/workspace/Sim-to-Real-SO-101-Workshop/datasets -v ./models:/workspace/Sim-to-Real-SO-101-Workshop/models so101-workshop:latest

Shell은 /workspace/Sim-to-Real-SO-101-Workshop에서 시작하며, 공통 Python environment인 /workspace/IsaacLab/env_isaaclab이 자동으로 활성화됩니다.

  1. 이 terminal을 열어 둔 채 이후 실습을 container prompt에서 진행하세요. 현재 실습을 마치거나 Ctrl+C로 중단한 뒤 종료가 완료될 때까지 기다리고, 같은 prompt에서 다음 명령을 실행합니다. Main shell을 닫으면 container도 종료됩니다.

단계에 host라고 명시되어 있지 않다면 이후 명령은 container 내부의 /workspace/Sim-to-Real-SO-101-Workshop에서 실행합니다. Mount된 docker/env의 설정은 container shell 시작 시 읽습니다. 일반 export는 현재 shell에만 적용됩니다. Robot port와 ID를 유지하려면 과정의 setenv helper를 사용하세요.

실행 중인 Container에 다시 접속하거나 추가 Shell 열기

Host terminal에서 container가 실행 중인지 확인합니다.

docker ps --filter name=so101-workshop

실행 중인 container에 shell이 필요하면 다음을 사용합니다.

docker exec -it so101-workshop bash

종료되어 있다면 host의 repository root에서 3단계를 다시 실행하세요. Mount된 dataset, model, output, 설정은 유지됩니다. 새 shell에서는 일반 export 변수를 다시 설정해야 합니다. 추가 shell은 선택 사항이며, simulation 평가에서는 같은 terminal의 background로 server를 시작합니다.

유지되는 파일#

Container mount와 영구 파일 위치 보기

Host 위치

Container 위치 / 용도

docker/env

/root/env: robot port와 ID 등의 설정

source/

Container repository의 workshop package source

datasets/

Container repository의 recording 및 download dataset

outputs/

Container repository의 training run과 기타 output

models/

Container repository의 download checkpoint

~/.cache/huggingface/

/root/.cache/huggingface/: Hub cache와 robot calibration

~/.cache/ovrtx/, ~/.cache/warp/

Renderer와 physics cache

Mount된 directory의 수정은 host에 유지됩니다. --rm 옵션은 main process가 끝나면 container를 제거합니다.

Simulation 확인#

  1. Container 안에서 task를 조회하고 physics-only 검사를 실행합니다.

list_envs
zero_agent --task Newton-So101-Teleop-Vials-To-Rack-v0 --cameras none presets=newton --visualizer newton

  1. Ctrl+C로 종료한 뒤 camera-rendering 검사를 실행합니다.

zero_agent --task Newton-So101-Teleop-Vials-To-Rack-v0 --cameras all presets=newton,ovrtx_renderer

ovrtx를 처음 실행하면 shader cache 준비에 몇 분이 걸릴 수 있습니다. Interactive camera display는 Teleoperating in Sim에서 다룹니다.

Camera 명령에는 명시적인 --cameras 선택과 presets=newton,ovrtx_renderer가 필요합니다. Physics-only 명령은 --cameras none presets=newton을 사용합니다.

단계별 Task 선택#

수집 및 평가 Task ID 보기

  • Leader-arm collection: lerobot_agent에 Newton-So101-Teleop-Vials-To-Rack-v0를 사용합니다. Domain Randomization에는 Newton-So101-Teleop-Vials-To-Rack-DR-v0를 사용합니다.

  • Scripted collection: vials_state_machine에 Newton-So101-Auto-Vials-State-Machine-v0 또는 Newton-So101-Auto-Vials-State-Machine-DR-v0를 사용합니다. Automated Data Collection을 따르세요.

  • Policy evaluation: lerobot_eval과 LeRobot policy server를 사용하며, task는 Newton-So101-Teleop-Vials-To-Rack-Eval-v0 또는 Newton-So101-Teleop-Vials-To-Rack-DR-Eval-v0입니다.

list_envs는 bare-arm, lightbox, automatic-reach task도 표시합니다. 선택한 수집 방식에 맞는 vial-to-rack task를 사용하세요.

Model 준비#

  1. Ctrl+C로 camera 검사를 종료하고 container 안에서 인증합니다.

hf auth login

  1. Datasets and Models에서 호환되는 LeRobot GR00T 1.7 checkpoint를 선택하거나 GR00T Post-Training으로 직접 학습합니다. Download한 파일은 models/ 아래에 둡니다.
