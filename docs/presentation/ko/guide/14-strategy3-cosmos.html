Sim-to-Real 전략 4: Cosmos로 Dataset 증강#

Lecture
이 Module에 필요한 준비물

이론 수업입니다. 연결된 robot이나 실행 중인 container는 필요하지 않습니다. 원본과 생성 video를 검토하고 학습에 유용한 variation을 논의합니다.

Physical AI용 omnimodel인 Cosmos를 살펴보고, robot policy 학습용 synthetic data 생성에 집중합니다. 원본과 생성 video를 통해 어떤 variation이 유효한 training example을 보존하는지 확인합니다.

학습 목표#

이 session을 마치면 다음을 수행할 수 있습니다.

  • Cosmos의 reasoning, world generation, action modeling 연결 방식 설명

  • Robot learning에서 synthetic video augmentation의 역할 파악

  • 생성 video가 원래 task와 motion을 유지하는지 평가

  • Augmentation이 policy에 도움이 되는지 시험하는 방법 설명

Domain Randomization과 Co-Training을 넘어#

전략 1에서는 설정된 simulation parameter를 Domain Randomization으로 바꿨습니다. Generative augmentation은 scene 외관을 변화시키는 또 다른 방법입니다.

예를 들어 Cosmos 3 video transfer는 원본 video와 depth, segmentation 같은 structural control로 시각적 variation을 생성해 simulator의 variation을 보완합니다. NVIDIA Cosmos 3 transfer examples

Cosmos란?#

NVIDIA Cosmos는 Physical AI용 world foundation model과 도구의 플랫폼입니다. Cosmos 3는 omnimodel로, reasoning, world generation, action generation을 하나의 architecture에 결합합니다. NVIDIA Cosmos overview

Cosmos 3 family는 language, image, video, audio, action sequence를 다룹니다. Mixture-of-Transformers architecture는 scene 이해와 해당 scene을 조건으로 한 output 생성을 모두 지원합니다. NVIDIA Cosmos 3 documentation

Robot learning에서는 다음과 같이 활용할 수 있습니다.

  • Understand demonstrations: Camera 영상의 object, interaction, event를 추론합니다.

  • Generate training data: Prompt와 다른 입력으로 video variation과 가능한 미래 scene을 생성합니다.

  • Explore outcomes: 여러 action에 따라 scene이 어떻게 변할지 예측해 planning과 평가를 지원합니다.

  • Build policy models: 특정 robot과 camera data로 world observation을 robot action에 연결하는 World Action Model (WAM)을 post-train합니다.

이 활용 사례는 NVIDIA Cosmos 3 capability overview를 따릅니다. 이번 실습은 data augmentation에 집중하며, 실제 학습·배포하는 policy는 GR00T 1.7입니다.

World Prediction과 Action Modeling 자세히 보기

Forward dynamics는 현재 observation과 제안 control로 다음 상태를 예측합니다. Inverse dynamics는 관측 state 변화를 설명하는 action을 추정합니다. Robot policy는 observation으로 task용 action을 선택합니다. NVIDIA는 Cosmos 3의 shared model로 이러한 서로 다른 활용을 보여줍니다. NVIDIA Cosmos 3 research

선택적으로 연구 예시의 입력·출력을 확인하고 workshop episode의 wrist/external image, joint state, action과 비교해 보세요.

Cosmos 동작 방식#

아래 video augmentation workflow를 살펴보세요. Cosmos 3는 prompt와 edge, blur, depth, segmentation 같은 control로 video generation을 유도합니다. NVIDIA Cosmos 3 transfer examples

Control Signal이 결과에 미치는 영향#

Control signal은 Cosmos가 원본 video의 어떤 부분을 보존할지 안내합니다.

  • Edges는 object 윤곽과 위치를 안내합니다.

  • Segmentation은 arm, rack, vial 등의 영역을 나눕니다.

  • Blur는 세부 묘사를 줄인 scene의 전체 색상과 배치를 제공합니다.

Rack hole, vial 위치, gripper 형태를 비교하세요. 외관을 바꾸면서도 원본의 세부 사항을 가장 잘 유지하는 control은 무엇인가요?

참고: Cosmos 3 Augmentation 재현

설정과 control-video 예시는 NVIDIA Cosmos 3 Diffusers transfer notebook에서 시작하세요.

SO-101 시험에서는 external-camera clip의 edge-control video를 만들고 주변 laboratory를 바꾸도록 prompt를 작성했습니다. nvidia/Cosmos3-Nano, 640 × 480의 121 frame, 30 FPS, diffusion step 50, prompt guidance 3.0, control guidance 1.5, seed 2026을 사용했습니다. 의도하지 않은 object도 변했으므로 학습 전에 생성 clip을 원본과 비교하세요.

Dataset 예시: Cosmos-Augmented Demonstration#

Cosmos Transfer dataset은 simulation episode 10개를 felt mat, foam rack, frosted vial이 있는 실제 영상처럼 바꿉니다. External과 wrist video를 모두 증강하되 기록된 state, action, timestamp는 유지합니다.

증강 Data 검토 기준#

Visual Diversity

  • Photorealistic rendering variation

  • 자연스러운 lighting 변화

  • Background와 texture 다양성

Scenario Variation

  • Background와 surface 변화

  • Lighting variation

  • 기록된 action label을 보존하는 외관 변화

Physical Consistency

  • Frame이 task geometry를 보존하는지 확인

  • Contact timing과 motion을 원본과 비교

  • 기록된 action과 맞지 않는 augmentation 제외

토의: Video Augmentation 평가#

위 원본과 생성 예시로 다음을 논의하세요.

  • 어떤 lighting, surface, background 변화가 학습에 유용할까요?

  • Vial 위치, gripper 형태, contact timing이 기록된 action과 여전히 맞나요?

  • 어떤 예시를 남기거나 제외할 것이며 이유는 무엇인가요?

  • 효과를 시험하려면 증강 data를 사용한 policy와 사용하지 않은 policy를 어떻게 비교할까요?

Vial 이동, grasp 변경, contact timing 변화로 기록된 action과 맞지 않게 된 예시는 제외하세요. 준비된 예시를 사용하는 이 수업에서는 Cosmos generation을 직접 실행할 필요가 없습니다.

핵심 내용#

  • Cosmos 3는 scene understanding, world generation, action modeling을 연결하며 video augmentation은 활용 사례 중 하나입니다.

  • Domain Randomization, 실제 demonstration, generative augmentation은 서로 다른 방식으로 training coverage를 넓힙니다.

  • Policy 학습 전에 생성 video와 기록된 action을 대조하세요.

  • 같은 task에서 policy를 비교해 augmentation 혼합이 실제 성능을 개선하는지 측정하세요.
