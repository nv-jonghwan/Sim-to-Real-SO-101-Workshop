Stage 1 · 폭넓게 재사용할 수 있는 representation

Pre-training은 이후 로봇 적응에 재사용할 수 있는 representation을 형성합니다. 폭넓은 visual·language data와 로봇 경험은 서로 다른 역할을 합니다. 이 diagram은 dataset 비율이나 모든 경우에 적용되는 training 순서를 지정하지 않습니다.

Stage 2 · Post-training 설정

Freeze된 component도 feature를 계산하지만 optimizer는 해당 parameter를 갱신하지 않습니다. 기본 workshop 예시에서는 vision과 language를 freeze하고 action component를 학습합니다. 그림은 component를 개념적으로 묶어 보여 주며, 정확한 학습 대상은 저장된 설정에 기록됩니다.

예시

기본 command는 --policy.tune_visual=false와 --policy.tune_llm=false를 사용합니다. 이 설정은 training에 영향을 주며, inference에서 사용 가능한 입력을 바꾸지는 않습니다.

Use the adapted policy with fixed weights

Stage 3 · 새 observation을 사용하되 optimizer update는 수행하지 않음

Inference는 새 이미지, instruction 문구, robot state를 받아 저장된 checkpoint와 processor로 action을 예측합니다. Feedback은 다음 observation을 바꾸며 checkpoint weight를 바꾸지는 않습니다.

예시

Rollout 중 arm을 움직인 뒤 vial의 다른 위치를 관찰할 수 있습니다. 이때 다시 예측하며, 해당 trial로 스스로 fine-tuning하지는 않습니다. Training data가 다루는 동일한 시작 조건에서 checkpoint를 비교합니다.

Training 입력 · 서로 정렬된 observation과 이후 action target

Post-training은 demonstration episode에서 window를 sampling합니다. 이미지, language, robot state, 이후 action target은 서로 호환되는 task data를 나타내야 합니다. Rollout에서 예상되는 시작 상태와 동작을 data의 다양성으로 충분히 다뤄야 합니다.

예시

Vial placement를 위해 다양한 vial pose와 grasp approach를 포함합니다. 익숙한 grasp 하나를 더 많이 반복해도 누락된 recovery 동작은 학습할 수 없습니다.

Use loss to guide weight updates

Training loop · Loss, optimizer, learning rate

Training objective는 sampling한 예측과 target으로 loss를 계산합니다. Optimizer는 학습 대상 parameter를 갱신하고, learning-rate schedule은 update의 크기를 조절합니다. Loss가 감소한다는 사실만으로 grasp나 placement의 성공을 측정할 수는 없습니다.

예시

Training step이 20,000이면 optimizer는 20,000번 update합니다. Training curve와 함께 자율 rollout으로 저장된 checkpoint를 평가합니다.

Optionally adapt visual features

통제된 실험 · Vision은 학습하고 language는 freeze

Unfreeze하면 vision encoder가 task 이미지에 적응할 수 있습니다. 학습 대상 parameter와 memory 사용량이 늘어나며 overfitting 위험도 높아질 수 있습니다. 효과를 확인할 때는 다른 training·evaluation 조건을 고정합니다.

예시

같은 dataset, batch size, action window, update budget, rollout 조건으로 freeze된 vision과 학습 가능한 vision을 비교합니다. 제공된 대안 command는 batch size와 window도 바꾸므로, 그 자체로는 한 가지 요인만 비교하는 실험이 아닙니다.
