단계나 객체를 선택하면 설명을 볼 수 있습니다.

Workshop code

Task configuration, controller, recording, evaluation을 결합합니다. Bridge는 LeRobot command를 simulation joint command로 변환하고, observation을 recording 또는 inference용으로 다시 변환합니다.

LeRobot

Teleoperator·robot interface, dataset format, policy tool을 제공합니다. 수집할 때는 leader가, 평가할 때는 policy가 action을 제공합니다. Workshop recorder는 이미지, joint state, action을 저장합니다.

Isaac Lab

Asset, observation, action term, reset, 성공 판정을 구성합니다. Environment step은 선택한 physics·rendering backend를 vial-to-rack task에 연결합니다.

USD assets

Workstation의 geometry, material, camera property, physical property를 정의합니다. Isaac Lab이 simulation용 asset을 불러오고 Omniverse library가 rendering에 사용할 scene을 관리합니다.

Newton

설정된 MJWarp solver와 collision pipeline으로 로봇과 객체의 dynamics를 진행합니다. 갱신된 pose가 simulation scene에 반영되고 joint observation이 됩니다.

Omniverse libraries

ovstage는 rendering에 사용하는 USD scene을 관리합니다. ovrtx는 갱신된 scene에서 wrist·external RGB 이미지를 rendering합니다. ovstream은 GPU render 결과를 browser로 streaming합니다. Isaac Lab은 이 camera 결과를 observation으로 제공합니다.
