과정 개요#

이 과정에서는 vision-language-action (VLA) model과 SO-101 robot arm을 사용해 vial을 rack에 넣는 unstructured pick-and-place of centrifuge vials task를 수행합니다.

빠르게 반복하고 동작을 검증할 수 있는 simulation에서 시작한 뒤, 실제 환경으로 옮겨갑니다.

이 workflow를 통해 sim-to-real gap을 직접 경험하고, 이를 줄이는 체계적인 방법을 적용합니다.

이 workshop에서는 Isaac Lab 3.0, Newton physics, ovrtx rendering, LeRobot, GR00T 1.7을 사용합니다.

학습 목표#

이 과정을 마치면 다음을 수행할 수 있습니다.

  • Configure: sim-to-real 실험을 위한 SO-101 robot 설정과 calibration

  • Collect: domain randomization을 적용한 teleoperation 또는 scripted controller 기반 demonstration data 수집

  • Train: GR00T를 사용한 robot manipulation용 vision-language-action (VLA) model 학습

  • Evaluate: 학습한 policy를 simulation에서 평가

  • Deploy: 실제 robot에 policy를 배포하고 sim-to-real gap 관찰

  • Explore: Domain Randomization, Co-training, HG-DAgger, Cosmos Augmentation, AnchorBench를 활용한 System Identification의 다섯 가지 sim-to-real 전략 탐색
