CODEX#

강사·TA·학생은 같은 repository와 skills/의 공통 스킬로 환경을 준비하고, 교재를 이해하고, 실습을 진행하며 관찰 결과를 함께 검토합니다.

한국어로 질문하고 Physical AI, GR00T, Co-Training, HG-DAgger와 같은 전문 용어는 영어로 사용해도 됩니다. 과정 질문은 교재를 바탕으로 답하고, 실제 장비 실습은 강사의 진행 순서와 station 준비 상태에 맞춰 수행합니다.

사용 환경 선택하기#

공통 workshop 폴더를 열고 자연스럽게 질문합니다. AGENTS.md가 요청에 맞는 skills/<name>/SKILL.md를 읽도록 안내합니다. 모두 같은 파일을 사용합니다.

ChatGPT app에서 시작하기#

Desktop app의 Codex 사용하기#

  1. 준비된 ChatGPT desktop app에 로그인하고 제품 선택 메뉴에서 Codex를 선택합니다.

  2. ~/Sim-to-Real-SO-101-Workshop을 로컬 project로 엽니다. 기존 project에서는 Edit project → Add folder로 추가하고, Make primary로 수업 저장소를 기본 폴더로 지정합니다. 새 채팅이 이 폴더에서 교재와 스킬을 찾습니다.

  3. 이번 수업에서는 Work in → This computer / Local을 선택하고 aidayseoul2026 branch의 준비된 checkout을 사용합니다. 채팅과 Workshop Container가 같은 수업 폴더를 사용하도록 맞춥니다.

  4. 이 project에서 채팅을 시작하고 아래 연결 확인 질문 후 환경설정이나 수업 질문을 입력합니다. Repository 지침이 공통 스킬 원문을 직접 읽도록 안내합니다.

폴더 연결은 Projects and chats, 실행 위치는 Codex environments를 참고하세요. Cloud 환경에는 사용할 파일과 도구가 따로 준비되어야 하며, Laptop의 USB 장치·실행 중인 Container·GPU가 자동으로 연결되지는 않습니다.

현재 작업 폴더와 Git branch를 확인해줘.
AGENTS.md, skills/so101-dli/SKILL.md, docs/seoul-workshop-schedule.md를 읽을 수 있는지 확인하고,
앞으로 수업 질문이나 실습 요청에 맞는 스킬을 찾아 적용해줘.
이번에는 파일 접근만 확인해줘.

App의 ChatGPT Work 사용하기#

ChatGPT 화면을 사용하려면 ChatGPT → Work를 선택하고 로컬 수업 폴더에 접근할 수 있는 project를 사용합니다. 지원 여부는 계정과 workspace 설정에 따라 다릅니다. 같은 연결 확인 질문으로 시작하세요. Use ChatGPT에서 자세한 내용을 확인할 수 있습니다.

파일 접근을 확인한 뒤 자연스럽게 질문하거나 공통 스킬 파일을 직접 지정합니다. 역할별 스킬 설치나 스킬 선택기에 항목을 추가하는 과정은 필요하지 않습니다.

로컬 폴더 접근이 없는 일반 web/mobile Chat에서는 관련 교재 파일을 첨부해 Q&A를 진행합니다. GitHub 링크만으로 저장소 스킬이 설치되거나 교실의 로봇이 연결되지는 않습니다. 이 과정은 로컬 스킬 폴더를 제공하며, 별도로 게시된 ChatGPT plugin은 없습니다.

Codex CLI에서 시작하기#

준비된 CLI를 사용합니다. 설치가 필요하면 공식 Codex CLI 안내를 따릅니다. Host terminal에서 수업 폴더로 이동하고 Codex를 시작합니다.

cd ~/Sim-to-Real-SO-101-Workshop
git branch --show-current
codex --version
codex

Branch가 aidayseoul2026인지 확인하고 필요한 로그인을 마칩니다. 자연어로 요청하거나 먼저 skills/so101-dli/SKILL.md를 읽도록 요청합니다.

수업용 스킬 설정하기#

모든 수업 스킬은 skills/에 있습니다. AGENTS.md는 환경설정이나 수업 질문에 맞는 스킬 원문을 읽도록 안내합니다. 교재의 상대 경로를 유지하도록 폴더 구조를 보존합니다. Symlink, 개인 폴더 복사, 역할별 활성화는 필요하지 않습니다.

스킬 선택기 UI에는 이 폴더들이 표시되지 않을 수 있습니다. 연결 확인 질문으로 AGENTS.md와 필요한 SKILL.md를 읽을 수 있는지 확인합니다. 이 수업은 원문 파일을 직접 읽는 방식으로 진행합니다.

파일을 읽을 수 없으면 선택한 project 폴더와 로컬 파일 접근을 확인합니다. 스킬 요청 자체가 추가 권한이나 robot 준비 상태를 보장하지는 않습니다.

환경설정#

공통 workshop project에서 환경설정을 해줘라고 요청합니다. Agent는 AGENTS.md와 skills/so101-dli-prepare/SKILL.md를 읽고 기존 설치를 확인한 뒤 준비 문서를 따라 진행합니다. 같은 스킬 파일로 설치와 수업 질문·실습을 지원합니다.

먼저 이 컴퓨터를 점검하려면 현재 컴퓨터가 DLI를 실행할 수 있는 환경인지 확인해줘라고 요청합니다. 준비 스킬이 Host의 기본 실행 조건, 누락된 도구·자산, 미확인 용량·runtime 검증 항목을 자동으로 보고합니다. 읽기 전용 보고서만으로 수업 실행을 보장하거나 설치·다운로드·robot 동작을 시작하지 않습니다.

python3 skills/so101-dli-prepare/scripts/preflight.py --format markdown

읽기 전용 계획 도구는 설치 단계와 명령을 보여주며 실제로 실행하지 않습니다.

python3 skills/so101-dli-prepare/scripts/setup_plan.py

합의한 source commit, 실제 model·dataset 경로, 명령·로그와 다음 작업을 runs/setup/<station>/에 기록합니다. 재개할 때는 검증한 설치·다운로드를 재사용합니다. Permission 오류나 검증하지 않은 runtime 항목은 미확인으로 남깁니다.

교재를 빌드하고 열기#

문서용 고정 dependency와 Git LFS media를 준비한 뒤 Host의 repository root에서 아래 명령을 실행합니다. 문서에는 robot Container나 GPU가 필요하지 않습니다.

uv sync --frozen
bash skills/so101-dli-docs/scripts/build.sh
python3 skills/so101-dli-docs/scripts/verify_html.py

두 언어의 문서를 빌드합니다. 같은 Laptop에서 빌드하고 브라우저로 볼 때는 사용 가능한 포트로 로컬 preview를 시작합니다.

python3 skills/so101-dli-docs/scripts/preview.py start --bind 127.0.0.1 --port 8095
python3 skills/so101-dli-docs/scripts/preview.py status

Preview를 시작한 뒤 같은 Laptop의 브라우저에서 교재 열기 또는 DLI준비와 진행 열기를 클릭합니다. 로컬 서비스 주소는 http://localhost:8095입니다. 문서 빌드만으로 서버나 브라우저가 실행되지는 않습니다. 다른 포트를 선택하면 링크의 포트도 바꿉니다.

localhost는 브라우저를 실행하는 컴퓨터를 가리킵니다. 다른 PC에서 접속할 때만 시작 명령의 127.0.0.1을 서버의 실제 LAN IP로 바꾸고 그 PC에서 preview가 보고한 URL을 엽니다.

Preview가 보고한 URL의 실제 응답을 확인해 사용합니다. 사용자가 볼 preview는 유지하며 PID·실행 명령·로그는 로컬에 기록됩니다. 해당 preview를 중지할 때는 preview.py stop을 사용합니다. 백그라운드 실행이며 재부팅 후 자동 시작은 아닙니다.

Software 준비와 robot 동작은 따로 점검합니다. 전원을 켜는 robot 실습 전에는 현재 작업자와 station 준비 상태를 확인합니다. Model cache나 연결 메시지만으로 실제 동작 성공을 판정하지 않습니다.

App 또는 CLI에서 수업 폴더를 연 뒤, 스킬 이름 없이 다음과 같이 질문합니다.

오늘의 일정이 뭐야?

Codex가 docs/seoul-workshop-schedule.md를 읽고 시간·주제·소요 시간·진행자를 표로 제시하는지 확인합니다. 입장·휴식·점심이 포함되고 모든 시간이 KST 기준인지도 확인합니다. 답변을 오늘의 일정과 비교하세요.

선택 사항: 파일을 직접 지정하기#

skills/so101-dli/SKILL.md를 읽고 오늘의 일정을 시간, 주제, 소요 시간, 진행자 표로 보여줘.

수업 시작이 09:00, 점심이 12:45–13:45, 마무리 종료가 17:15인지 확인합니다. 세션별 진행자는 상세 일정의 각 행을 기준으로 확인합니다. 이 예제는 문서를 읽는 작업이므로 robot이나 simulation을 시작할 필요가 없습니다.
