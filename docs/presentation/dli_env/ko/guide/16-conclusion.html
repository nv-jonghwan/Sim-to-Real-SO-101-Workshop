다룬 다섯 가지 전략#

전략

접근 방식

주요 효과

1. Domain Randomization

Simulation parameter 변화

설정된 visual 및 scene variation에 대한 robustness

2. Co-training

Simulation과 실제 data 혼합

실제 distribution을 더 잘 반영

3. HG-DAgger

Human correction과 원래 demonstration 혼합

Policy에 도움이 필요한 state를 집중 보완

4. Cosmos Augmentation

Synthetic visual diversity 생성

Visual variation에 대한 robustness

5. System Identification

측정한 robot 동작에 맞춰 simulation parameter fitting

실제에 더 가까운 actuator dynamics

주요 교훈#

  1. Gap은 실제로 존재합니다 — Simulation 성공이 실제 성공을 보장하지 않습니다.

  2. 여러 전략을 조합하세요 — 하나의 접근으로 모든 문제를 해결할 수 없습니다.

  3. 측정이 개선을 가능하게 합니다 — System Identification은 actuator parameter와 관측 motion을 연결합니다.

  4. 반복이 중요합니다 — 한 번의 시도보다 체계적인 개선이 효과적입니다.

  5. 기록이 중요합니다 — 기록한 observation이 판단의 근거가 됩니다.
