Sim-to-Real 전략 5: AnchorBench를 활용한 System Identification#

Lecture
이 Module에 필요한 준비물

Video와 공개된 비교로 System Identification을 설명합니다. 연결된 robot이나 실행 중인 workshop container는 필요하지 않습니다.

같은 joint command라도 simulation과 hardware의 motion이 다를 수 있습니다. **System Identification (SysId)**은 측정된 동작에서 model parameter를 추정해 simulation이 실제 system을 더 잘 표현하도록 합니다. AnchorBench SysID layer 유무에 따른 SO-101 motion과 policy 동작의 차이를 비교합니다.

학습 목표#

  • 측정한 robot motion을 System Identification에 사용하는 방법 설명

  • Baseline, fitted, measured motion의 차이 파악

  • 동일한 action과 초기 조건이 중요한 이유 설명

  • Actuator-model 검증과 후속 policy 평가 구분

측정에서 Simulation Model로#

Position-controlled joint의 응답은 target angle만으로 결정되지 않습니다. Drive stiffness, damping, effort limit, armature, friction이 tracking과 settling에 영향을 줍니다. SysId는 이런 parameter를 조정해 simulation motion과 실제 측정의 차이를 줄입니다.

정보가 풍부한 motion을 기록하고 일부로 model을 fitting한 뒤 fitting에 쓰지 않은 motion으로 검증합니다. 좋은 fit은 조정에 쓰지 않은 동작도 설명해야 합니다. Policy 성공은 추가 시험이며 motion tracking 개선만으로 pick-and-place 성능 향상이 입증되지는 않습니다.

Anchor-Lab and AnchorBench#

NVIDIA Anchor-Lab은 SO-101 arm과 H1/G1 humanoid의 실제 실험에서 얻은 timestamp 포함 측정 자료입니다. SO-101에는 frequency sweep, backlash 검출 motion, workspace sweep이 포함됩니다. 각 motion은 응답의 다른 특성을 드러내며 simulation model의 calibration과 검증 기준을 제공합니다.

SO-101 AnchorBench 비교는 fitted actuator parameter를 policy-learning workflow에서 연구하는 예시입니다. Baseline/fitted profile, paired policy checkpoint, 재현 안내, 비교 video를 제공합니다. Paired demonstration은 command와 scene을 맞춰 actuator model 효과를 분리합니다.

공개 bundle은 fitted profile과 재현 기록을 제공하지만 Anchor-Lab telemetry로 새 AnchorBench model을 fitting하는 전체 명령 순서는 포함하지 않습니다.

Teleoperation 비교: Default와 SysID Asset#

제대로 조정되지 않은 robot asset은 실제 robot과 다르게 움직일 수 있습니다. Default SO-101, fitted SysID layer 적용 asset, 실제 측정 motion을 겹쳐 차이로 actuation gap을 보여줍니다.

SysID Motion 예시: Chirp Sweep#

Chirp sweep은 진동 명령의 frequency를 점차 바꿉니다. 진행에 따른 measured motion의 lag, amplitude, settling을 보세요. 하나의 정적 pose로는 이런 응답 차이를 볼 수 없습니다.

Workshop 비교: SysId와 Original Actuator#

왼쪽 SysId와 오른쪽 original actuator의 paired trial 10개입니다. 5배속으로 재생됩니다.

이 policy는 task를 견고하게 수행할 정도로 학습되지 않았지만 vial로 접근할 때의 실패를 보여줍니다. Gripper가 grasp 가능한 위치에 도달하는지 집중해서 보세요. Approach 실패와 grasp 또는 placement 문제를 구분합니다.

Simulation 평가 결과#

별도의 simulation 비교에서 두 policy를 두 actuator profile로 각각 평가했습니다. 각 셀은 같은 scene reset, 16-action execution horizon, 30초 trial limit으로 실행한 100 trial 중 placement 성공 수입니다.

SysID data로 학습한 policy는 두 profile 모두에서 더 좋은 성능을 보였습니다. 같은 policy의 평가 actuator를 original에서 SysID로 바꾸면 성공률이 10 percentage points 높아졌습니다.

SysID가 항상 이런 결과를 내는 것은 아닙니다. 이처럼 큰 simulation 차이는 original model의 tuning이 충분하지 않았을 가능성을 시사합니다.

핵심 내용#

  • SysId는 실제 측정으로 simulation parameter를 추정합니다.

  • Timing, 단위, motion coverage가 fit의 의미를 좌우합니다.

  • 조건을 맞춘 demonstration으로 actuator profile의 효과를 분리합니다.

  • Motion model 정확도와 후속 task 성능을 모두 검증하세요.
