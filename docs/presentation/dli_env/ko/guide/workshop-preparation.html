Workshop 준비 참고#

운영자는 수강생 도착 전에 각 station의 container를 build하고 실습 model을 download하세요.

Repository Clone과 Container Build#

Git LFS와 Docker가 설치된 host에서 다음을 실행합니다.

git lfs install
cd ~
git clone --branch aidayseoul2026 --single-branch https://github.com/nv-jonghwan/Sim-to-Real-SO-101-Workshop.git
cd Sim-to-Real-SO-101-Workshop
git lfs pull
docker build -t so101-workshop -f docker/Dockerfile .

실습 Model Download#

Hugging Face CLI(hf)로 host에서 실행합니다. Container가 mount할 host cache를 채우므로 실습 명령에서 공개 model ID를 그대로 사용할 수 있습니다. Container 시작 전에도 download 가능합니다.

CLI가 container에만 있다면 아래 cache mount를 적용한 뒤 내부에서 같은 명령을 실행합니다.

hf download nvidia/GR00T-N1.7-3B
hf download sreetz-nv/so101_newton_dr500_vision_h32_b32_20k_20260929
hf download sreetz-nv/so101_real10_sim75_vision_h16_b64_20k_20261011
hf download sreetz-nv/so101_real10_sim75_hgdagger29_vision_h16_b64_20k_20261013
hf download liorbenhorin-nv/so101_sim_manual_perception_newton_20261008_GR00T17_20k
hf download liorbenhorin-nv/so101_vision_dr_i1_GR00T17_20261013
hf download liorbenhorin-nv/so101_vision_dr_i5_GR00T17_20261013
hf download sreetz-nv/so101-clean-up-vials-into-rack-50-groot-n17-relact-bs64-20k-20260628_johnny_42

Model Precision 설정#

Download 후 실습 policy 7개 각각의 config.json을 직접 수정해 다음과 같이 설정합니다.

"model_params_fp32": false,
"use_bf16": true

Container에 mount되는 Hugging Face cache의 policy configuration을 사용합니다. 보통 host의 ~/.cache/huggingface/hub/models--<owner>--<model>/snapshots/<revision>/config.json입니다. 평가할 revision을 선택하세요. Local model directory라면 그 안의 config.json을 수정합니다.

다른 설정은 유지하고 위 모든 실습 policy에서 반복합니다. nvidia/GR00T-N1.7-3B base model은 수정하지 마세요. 새 revision을 download한 뒤 다시 확인하고, 수정 후에는 실행 중인 policy process를 재시작합니다.

Starting-Pose Data Download#

Host의 workshop checkout에서 실행합니다. --start_pose_dataset에 쓰이는 모든 dataset의 metadata와 joint-state data만 내려받고 video는 제외합니다. Container의 ./datasets mount로 loader가 기대하는 위치에 파일이 놓입니다.

for DATASET_ID in \
  sreetz-nv/so101_newton_dr500_20260923 \
  sreetz-nv/so101_sim_manual_perception_newton_20261008 \
  sreetz-nv/so101_real10_sim75_20261011 \
  sreetz-nv/so101-clean-up-vials-into-rack-50_20260628_131121 \
  liorbenhorin-nv/so101_vials_procedural_left_125ep_20261013 \
  liorbenhorin-nv/so101_vials_procedural_all_125ep_20261013
do
  hf download "$DATASET_ID" --repo-type dataset \
    --include "meta/**" "data/**" \
    --local-dir "./datasets/$DATASET_ID" || break
done

HG-DAgger의 starting pose는 correction segment가 아닌 sim-teleoperation dataset을 사용합니다.
