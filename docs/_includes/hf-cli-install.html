Install the hf CLI

The hf CLI is included in the huggingface_hub Python package. Run these commands in a Host terminal to install it in a separate environment for your user.

If hf is already available, skip installation and check your account. This Host installation is separate from the workshop Container.

  1. Create a dedicated Python environment.

    python3 -m venv ~/.local/share/hf-cli

  2. Install the package containing the CLI.

    ~/.local/share/hf-cli/bin/python -m pip install "huggingface_hub==2.4.0"

  3. Make the command available from your user bin directory. Skip the link command if it already exists.

    mkdir -p ~/.local/bin
ln -s ~/.local/share/hf-cli/bin/hf ~/.local/bin/hf

  4. Add that directory to PATH for the current terminal session.

    export PATH="$HOME/.local/bin:$PATH"
hash -r

    For new Bash sessions, add the export line to ~/.bashrc if that directory is not already on PATH.

  5. Check that the CLI is available.

    hf version
hf --help

  6. Authenticate if needed, then verify the account used for Hub operations.

    hf auth login
hf auth whoami

    HF_USER is a separate shell variable for building repository IDs; setting it does not log you in. Enter credentials only through the login prompt.
